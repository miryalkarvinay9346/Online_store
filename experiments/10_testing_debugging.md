
# Experiment 10: Testing and Debugging

## Aim
To understand Flutter unit tests, widget tests, and debugging techniques.

## Testing concepts

- Unit tests verify individual functions and business logic.
- Widget tests verify rendered widgets and user interactions.
- Integration tests verify application behavior across screens.

## Suggested procedure

1. Open the project in a Flutter development environment.
2. Run `flutter pub get`.
3. Run `flutter analyze` to identify static analysis issues.
4. Run `flutter test` to execute automated tests.
5. Use Flutter DevTools to inspect the widget tree and diagnose layout issues.
6. Fix errors and repeat the tests.

## Expected result

The developer learns how to inspect errors, test widget behavior,
and improve application reliability.

## Evidence

Add screenshots of successful test output and debugging tools
to the `outputs/` directory after running the application.
